# 📇 Developer Profile Card

A clean, responsive personal digital business card component built using semantic HTML5 structures and custom modern CSS3 variables.

### 🛠️ Tech Stack & Skills
- **Structure:** HTML5 Layout Design
- **Styling:** CSS3 Custom Properties (Flexbox, Card Layouts, Colors)

### ✨ Key Features
- **Modern UI Styling:** Employs dark-mode backgrounds matching industry developer profiles.
- **Full Responsiveness:** Utilizes dynamic CSS scaling to adjust smoothly to modern screen layouts.
